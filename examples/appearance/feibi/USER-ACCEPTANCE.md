# 菲比音效版：使用步骤

七组动画、四边与图标已由用户确认正常。本次新增点击与提醒音效，不要求重复整套验收。

1. 从 Release 解压 `Char-1.0.0-examples.zip`，得到 `Examples/feibi.charpet`。仓库内对应 `examples/appearance/feibi/packages/feibi.charpet`。
2. 打开 Char **设置 → 桌宠与动效**。若已装同 ID 的旧菲比，先保存旧包，再点 **删除当前形象**；随后点 **导入形象…**，选择新版 `feibi.charpet` 目录本身。导入即选中，无脚本确认。
3. 开启 Char 的音效，点击桌宠或气泡，应播放菲比语音。音量为 55%，4 秒内再次点击不会重复触发；静音后不播放，切换形象停止旧音效。
4. 在设置的音效项选择“重置”，使用形象提供的提醒音（已明确选择的用户音效优先）。等待现有 Agent 自然产生一次提醒，经过过滤后也应播放菲比语音；不用为此发起模型请求。提醒音与点击音各冷却 4 秒，静音同样有效。
5. 形象和声音资源一起保存在用户私有副本中。升级安装 App 不会覆盖旧私有副本，因此旧包必须重新导入才能获得音效。

本次按要求未执行新的测试或播放检查。声音实际效果由用户体验；若有问题，只反馈点击目标、静音状态与发生时间即可。
