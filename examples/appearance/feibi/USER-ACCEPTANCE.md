# 菲比官方示例：GUI 验收

本次需要配套的本地宿主。**正式版和已安装菲比不需要删除或覆盖。** 验证版使用相邻的独立 Profile，图标同步也仅修改验证版副本。全程无需终端命令。

在以下路径中将`<Char仓库路径>`替换为你的本地仓库绝对路径。本机验证包旁的USER-ACCEPTANCE.md已填好实际路径。

完整的本轮声音、计龄、拖动、Space与Claude退出检查见[体验验收](../../../docs/experience-acceptance.md)。

## 开始

1. 从 Char 状态栏菜单选择 **退出 Char**，保留 `/Applications/Char.app`。
2. 在 Finder 选择“前往 → 前往文件夹…”，粘贴 `<Char仓库路径>/build/experience-preview/`。双击其中的 **Char.app**。不要拖到 Applications，不开启登录启动。
3. 点击新 Char 的状态栏图标 → **设置 → 桌宠与交互 → 导入形象…**。
4. 用文件选择器的“前往文件夹”粘贴 `<Char仓库路径>/examples/appearance/feibi/packages/`，选中整个 `feibi.charpet` 目录，点击导入。
5. 出现 **启用形象脚本？** 时确认启用，然后选中 **菲比 · Phoebe**。如已在本验证版导入同ID包，先删除验证版中的旧副本再导入；正式版独立配置不受影响。

## 检查清单

- **主题与辨识**：先选日光，再选月夜；脸型/肤色不变，金白蓝与蓝紫点缀可区分。主题不会自动变化。状态栏图标随主题改变。
- **静置与跟随**：在36、48、88pt观察呼吸与完整眨眼；鼠标往八方向移动，头部轻转、瞳孔轻移，无旧眼睛双影。鼠标停住时不抖动。
- **五种放置**：设置选桌面、左、右、上、下。上边缘向下探头，下边缘向上；两侧姿态有镜像/倾斜变化。探出后不要突然转回桌面姿态。眼睛/帽子可辨，隐藏后无残留头部。
- **动作**：点桌宠、拖拽后释放，观察预备、回弹与闲置接缝。去另一块屏幕的应用窗口再返回，桌宠与气泡应协调迁移。手动换Space时不突然重播。
- **气泡**：使用你已开启客户端的自然事件。黑/白应用背景上查看轮廓和真实Agent图标；CLI角标清楚。悬停气泡时角色专注、气泡律动，离开恢复；折叠后滚轮轮换应弹性缓入缓出，点击应破碎并沿用默认跳转。
- **事件**：客户端有提问/审批时好奇，有结构化失败等问题时担忧，轮次结束短暂开心；同一客户端重复状态不反复重播。回城（Ctrl+B）欢迎后恢复闲置。没有对应原生信号的客户端不会凭内容猜测。
- **声音**：开启声音，连续点桌宠，后一次立即打断前一次；点气泡不响。提问/审批/未分类、问题、轮次结束分别播放三条指定原声。同批每类一次，提醒期间点击只有视觉反馈；静音后不响，解除静音不补播。三类均可选择、试听和恢复形象默认。
- **计龄**：保留未查看等待项，0/60/299/300/301秒检查44→66pt先快后慢，5分钟仅一次重复。增加新项不重置旧项；查看/忽略后按剩余项，恢复后变淡、保留可点击入口并停止放大。折叠/隐藏期间继续计龄，重启不回放。
- **用户偏好**：关闭“使用形象行为偏好”，气泡距离等恢复用户偏好，回城导航仍按用户策略；重新启用后变紧凑。
- **减少动态效果**：系统设置 → 辅助功能 → 显示 → 减少动态效果。动画冻结，静态跟随仍可用；关闭后恢复。
- **图标**：查看设置“安装图标已同步”，在 Finder 查看 `build/experience-preview/Char.app` 的探头图标；切主题应改变，再选默认形象应恢复默认图标。Finder可能需重新打开所在目录。Launchpad不会自动收录 build 中的本地验证版，本阶段不安装到 Applications。
- **性能**：设置 → 性能与诊断，开启监控后静置。宿主计入原生绘制，菲比脚本单独显示；不为每张图片声明虚构独占RSS。
- **重启**：退出并再次打开验证版，所选主题与行为偏好保持，脚本正常。

## 恢复

1. 在验证版选择 **默认形象**，等待安装图标显示同步；删除验证版的菲比包，确认脚本停止。
2. 退出验证版。在 Finder 打开 **`/Applications/Char.app`**，原来的配置与形象仍保留。
3. 验收完成后可将 `build/experience-preview/` 整个目录移到废纸篓；其中 Profile 是测试数据，不是正式版数据。

如需要辅助功能，系统中选择的是当前验证副本；不要移除正式版的授权。Focus应用级路径可在无辅助功能时使用。验收反馈按“主题/大小/放置/动作/实际表现”描述即可，不必提供聊天内容。

### 本次内存优化的重点复验

退出正在运行的Char，再打开 `build/experience-preview/Char.app`。此版本使用新的独立Profile，需要按开始步骤导入一次；无需删除正式版中的菲比。检查日光/月夜、36/48/88pt、四边、跟随与完整眨眼；点击/拖拽、Space和滚轮仍按前面的步骤确认。

设置→性能与诊断，开启后等2秒：“内存”现在是physical footprint，展开“计量详情”可看RSS；不要与之前RSS截图直接比较。菲比行显示脚本进程用量及宿主内图片缓存；没有常驻进程的集成显示“运行于宿主”。若两个集成使用同一图标，详情显示共享部分，不能相加。暂停应冻结数字，恢复应跳过暂停CPU时间；换主题/尺寸或删除形象后，缓存数字在下一次采样更新。

开发已完成隔离同条件内存/CPU对比。你只需反馈画面、图标与交互是否正常，以及面板数字/归属是否易懂，无需模型请求或终端命令。

本次调整：贴边露出收至肩部，边缘中央稍粗、两端渐隐的白线及柔光应可辨且不挡点击。快速切Space不再播放宿主恢复；只切一屏时不能往返跳屏。设置标题整行可点击。
