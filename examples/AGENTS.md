# 示例开发入口

根据当前任务读取一份完整开发指令，再开始工作：

- 客户端监控、跳转、准确起点或安装维护：读取 `examples/integrations/AGENTS.md`。
- 自定义角色、动画、跟随、主题、气泡、音效或图标：读取 `examples/appearance/AGENTS.md`。
- 组合已有内置能力的配置包：读取 `examples/configuration/AGENTS.md`。

以上路径相对于 Char SDK 根目录（含 `Package.swift`）。修改现有示例沿用其工作区；制作新作品按对应指令选择独立工作区。仅按本次需求读取示例实现和 SDK 参考。
