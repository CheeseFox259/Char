# 桌宠形象的自定义范围

Char 1.0.0的schemaVersion 2支持以下范围；旧v1继续兼容七种PNG动作及图标。字段、限制、实际默认值见[完整API](appearance-v2-api.md)。

| 能力 | 包可自定义 | 宿主保留的合同 |
| --- | --- | --- |
| 角色与动作 | 外形、表情、帧序/FPS、七种动作及额外命名动作 | 像素预算、Reduce Motion、迁移生命周期 |
| 每边造型 | desktop/四边各自clips、anchor、rotation、mirrorX、tracking | 屏幕可见范围、稳定落位与迁移 |
| 鼠标跟随 | 实时瞳孔图层位移、八方向头部姿态 | 原生平滑、方向换算和缓存；不是骨骼/网格引擎 |
| 主题 | 帧资源、每边姿态、跟随图层、气泡皮肤、软件图标 | 固定清单资源，热切与持久化 |
| 音效 | WAV/AIFF/M4A/MP3/AAC/CAF/FLAC（含wave/aif/aifc别名）、事件/动作触发、音量/冷却 | 系统实际解码、全局静音、资源限定、旧音效清理 |
| 脚本与触发 | Char事件→受限动作；按Agent状态、hover、drag、点击和回城响应 | 无命令/文件/网络API，无逐帧回调，超时终止helper |
| 气泡皮肤 | 外壳、状态颜色、系统字体、CLI图案、悬停轮廓/形变、破碎参数、轮换曲线与节奏 | Agent官方图标/状态语义、圆形点击区、折叠规则 |
| 行为与布局 | 宠物/气泡点击、回城锚点策略、焦点跟随、吸边阈值、拖拽碰撞、气泡距离/容量/弧与顺序 | 用户可禁用形象行为偏好；公共锚点/导航结果仍由宿主管理 |
| 命中区域 | 宠物多个归一化rect/ellipse，随anchor/旋转/镜像换算 | 气泡标准点击区、透明窗口事件穿透 |
| 软件身份 | 独立图标及主题图标，运行/状态栏/Finder/Launchpad同步 | 可写ad hoc安装事务重签；原Release可恢复，可能需重授AX |

仍不支持：任意本机命令、外部应用自动化脚本、第三方原生库、网络资源热下载、骨骼/动态网格、包内字体安装、任意系统窗口层级、改变系统Space转场曲线或扩大系统权限。Agent图标及监控/精准导航仍由集成能力插件提供。

## 边缘落位修复

边缘落位曾因只在edgePeek/edgeHide旋转，导致idle突然回到桌面姿态；宿主v0.2.2已修复，上边缘与侧边沿所有动作保持朝向。v2可进一步提供独立每边造型。开发者不应修改宿主或用压缩全部角色/挪动统一anchor绕过这个旧缺陷。
