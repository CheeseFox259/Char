# Char v0.2.1 — 连续的气泡状态

## 修复与体验

- 修复运行中会话进入停顿或轮次结束时，气泡在提醒过滤期内消失、之后重新出现的问题。
- 既有运行气泡在过滤期间保持原位并显示等待确认；达到阈值后变为对应提醒，恢复运行时平滑切回。提醒阈值与音效时机保持有效。
- 气泡壳体和 Agent 图标持续保留，仅状态标记通过非线性交叉淡化和轻微弹性变化过渡。减少动态效果时改为短淡化。
- 已查看、手动忽略、关闭与插件停用继续清理相应内容；修复不会复活已清除的提醒。

## 验证

新增真实路由回归检查，覆盖运行→过滤停顿→结束、恢复运行、精确焦点确认与关闭。原生 App 检查连续切换时同一气泡的可见性、位置、图标缓存、状态图层动画、破碎图像与减少动态效果；完整项目检查与原生烟测复验通过。所有自动导航测试均使用隔离 fixture，没有发起模型请求。

## 安装

macOS 13+，Universal ZIP/DMG 包含 Apple Silicon 与 Intel。退出旧版后将 Char.app 替换至 `/Applications/Char.app`。设置、插件与形象保留。发行包为 ad hoc 签名，尚未 Developer ID 签名或公证；辅助功能状态以安装后的实际检查为准。
