# Char v0.2.0 — 能力插件

## 新增

- v3 `.charintegration` 包：独立进程适配器提供监控、访问、准确回城起点及安装维护；新客户端无需重新编译 Char。
- 导入、自检、启停、同 ID 更新与删除可在 Char 运行时生效。原生客户端加载扩展或 Hook 可能仍需重载。
- pi、Kimi CLI/App、DeepSeek 的所属集成支持安装、升级、自检、移除及私有备份，使用稳定本地事件入口。
- 首次、最近或关闭起点策略；可选择是否捕获应用级起点。
- 插件骨架生成、生产格式校验、协议自检、事件回放和三份通用开发 AGENTS.md。

## 修复

- pi 观察失败不再直接写终端 stdout/stderr，避免污染 TUI。
- Kimi 迁移过期 Hook 路径并去重历史 Char Hook，保留其他用户配置。
- 客户端扩展使用稳定运行目录，避免依赖开发构建路径。

## 安装

macOS 13+；Universal ZIP/DMG 包含 Apple Silicon 与 Intel 二进制。将 Char.app 安装到 `/Applications`，替换旧版。首次安装不会自动写入客户端配置；已有集成可在设置 → 插件维护菜单更新，然后由用户安排客户端重载。

包采用 ad hoc 签名，尚未 Developer ID 签名或公证。更新后若辅助功能状态未授权，请在系统设置重新添加 `/Applications/Char.app`。

## 验证与范围

项目检查、独立适配器生命周期/监控/导航协议测试、原生 App 烟测与签名检查通过。导航协议测试使用模拟目标，没有发起模型请求或代替用户重启工作会话；真实新客户端的准确会话导航需逐插件验收。进程隔离不等于权限沙箱，第三方适配器具有当前用户权限。

原 v0.1.2 性能报告保留版本与条件；新增适配器测量不冒充整体性能。详见仓库 `docs/capability-plugins-verification-2026-10-06.md`。
