# Char First Release Implementation Plan

> **For agentic workers:** Execute through the user-invoked `implement-spec` workflow: one implementer branch/worktree per ticket, merger agent integration, then Standards/Spec review. That explicit workflow replaces the execution-choice prompt in writing-plans.

**Goal:** Deliver a local macOS companion that observes native Agent sessions, surfaces attention bubbles, activates the owning app with graphical fallback, and returns through a verified or explicitly degraded source anchor.

**Architecture:** A Swift package separates a deterministic attention/return state machine from local-record observation and macOS effects. AppKit hosts a nonactivating companion panel with SwiftUI graphics/settings; only settings and display positions persist. Native session content is never sent to a service or shown in daily bubbles.

**Tech Stack:** Swift 6 in Swift 5 language mode, macOS 13+, SwiftPM, AppKit/SwiftUI, ServiceManagement, executable Swift acceptance checks. The installed Command Line Tools lack XCTest, so the checks throw on failure and return a nonzero exit code. A local VS Code extension and Tabbit Apple Events provide optional accurate return integrations. No external package or web font is required.

## Shared contract (#4 establishes these definitions first)

```swift
public enum WorkEnd: String, CaseIterable, Codable, Sendable {
    case claudeCode, codexCLI, codexDesktop
}
public enum StopReason: String, CaseIterable, Codable, Sendable {
    case question, approval, turnEnded, failure, rateLimit, contextExhausted, unclassified
}
public struct SessionKey: Hashable, Codable, Sendable {
    public var workEnd: WorkEnd
    public var nativeID: String
}
public struct SessionTarget: Hashable, Codable, Sendable {
    public var bundleIdentifier: String
    public var tmuxPaneID: String?
    public var processID: Int32?
    public var sourcePath: String?
}
public enum SessionState: Equatable, Codable, Sendable {
    case running, stopped(StopReason), closed
}
public struct ObservationEvent: Equatable, Codable, Sendable {
    public var key: SessionKey
    public var target: SessionTarget
    public var timestamp: Date
    public var state: SessionState
    public var isChild: Bool
}
public enum AnchorAccuracy: String, Codable, Sendable { case exact, application }
public struct ReturnAnchor: Equatable, Codable, Sendable {
    public var id: String
    public var bundleIdentifier: String
    public var token: String
    public var accuracy: AnchorAccuracy
}
public enum NavigationOutcome: String, Codable, Sendable { case exact, fallback, unavailable }
public struct FocusContext: Equatable, Sendable {
    public var exactSession: SessionKey?
    public var isAgent: Bool
    public var sourceAnchorID: String?
}
```

All public structs have public initializers. `CharSettings` holds a 10-second filter, 300-second Hold grace, enabled sound, optional local audio path, and enabled login launch; normalization rejects nonfinite/negative times. Remaining engine snapshot types and methods are owned by #6, with callers updated together.

## Coverage and boundaries

Observation (#5) covers the three work ends, native ownership, startup/sleep/child rules and local privacy. The acceptance seam (#6) covers reasons/timing/order/dismissal/sound/Hold. Platform (#7) covers first-release app fallback and supported returns. UI (#8) covers graphics/settings/desktop behavior. Integration (#9) reports runtime and release limits. Exact Warp pane, Codex chat and WeChat chat capabilities are separate follow-ups, not hidden success assumptions.
