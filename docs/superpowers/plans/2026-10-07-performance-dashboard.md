# 设置性能面板

面板默认关闭，用户开启后每秒读取宿主及宿主拥有的适配器/形象脚本进程；不运行ps、不枚举其他应用、不读取客户端内容。关闭后停止采集并保留本次统计，清空按钮重置。统计不写磁盘。

- [x] 原生proc_pid_rusage读取CPU累计时间/RSS/进程身份，差分计算单核100%口径CPU。
- [x] 暴露现有宿主进程身份；区分宿主共享开销、形象脚本、集成适配器。无独立进程不伪造0或独占用量。
- [x] 设置中的双语小面板：开关、CPU/RSS当前/平均/峰值、有效样本/采样时长、清空。内存平均为样本平均；CPU平均按有效区间时长加权。
- [x] 固定1秒采集、后台批量读取、禁止重叠任务，数据保留范围限当前启用插件，PID/启动身份变化重建差分基线。
- [x] 数学/生命周期/真实进程检查及原生设置路径检查，本地检查成功，发布/Release安装记录见验证报告。

实际应用权限与音效/缓存效果保持用户验收。首次开启仅能统计开启后的区间，不声称覆盖插件此前整个启用期。
