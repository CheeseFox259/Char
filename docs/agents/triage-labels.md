# Triage Labels

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予实施 |

技能提到规范角色时，使用对应 GitHub 标签。
