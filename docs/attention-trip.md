# 注意力往返行为草案

## 入口

- 首版在 macOS 单机运行，登录后默认自动启动，监视 Claude Code TUI、Codex CLI、Codex Desktop、DeepSeek Harness Desktop、Kimi Code、pi 的本机会话。CLI 直接在这台 Mac 上的 Warp 或 Warp + tmux 中运行；char 不接管原生会话的启动。
- 启动时不回放已有等待；启动前创建、启动后才停下的 CLI 会话仍需被观察并提醒。Mac 睡眠期间发生且唤醒后仍有效的新事件需显示。
- 会话连续停下达到全局过滤阈值后才产生注意力项，默认 10 秒，设置中可调整；能够验证准确会话已获得键盘焦点时只记录状态，不弹气泡。Warp 当前无法可靠判定 pane 焦点时不得据此压下提醒或清除注意力项；目标 pane 即使在分屏中可见，也不等于已获焦点。
- 桌宠旁按工作端显示气泡；每个气泡显示最紧急原因的图形及未查看数量。运行中会话只显示计数。气泡不显示任意提问或命令原文。
- 同一工作端内，当前仍在等待的项先于已恢复项；提问、审批先于异常与限制，轮次结束最后；同级等待最久的先到。每会话只保留当前一项。Agent 在气泡出现后自行继续工作时，气泡保留并带已过去标记，直到准确查看或忽略。
- 气泡左键直接跳转；右键只忽略当前排首的会话。普通状态下左键桌宠仅给轻微视觉回应，桌宠右键菜单提供设置、静音与主动结束 Hold。设置中提供图形图例，日常气泡和降级反馈无可见文字。
- 提示音默认开启，短时间多项合并响一次；使用者可静音并选择一个本地音频文件。
- 气泡和桌宠在所有 Space 与全屏应用上可见。只有一个桌宠，跟随当前操作所在屏幕，并记住各屏的位置。

## 往返

返回最初来源称为“回城”。Ctrl+B 仅在 Hold 有效时注册；无 Hold 时由前台应用正常处理。注册冲突可在设置中查看。

| 当前状态 | 事件 | 结果 |
| --- | --- | --- |
| 普通 | 点击气泡，成功捕获准确来源并切换到工作端 | 保存来源为返回锚点，进入 Hold；若未到达准确 Agent，会话仍未查看。 |
| 普通 | 点击气泡，无法准确捕获来源 | 仍尝试跳转；不进入 Hold。 |
| Hold | 点击其他气泡 | 保留最初的返回锚点，切换到下一个 Agent。 |
| Hold | 点击桌宠或按 Ctrl+B 回城并准确聚焦来源 | 结束 Hold。 |
| Hold | 手动回到准确来源，或微信降级来源的同一应用实例 | 静默结束 Hold。 |
| Hold | 点击桌宠或按 Ctrl+B 回城至微信应用级来源 | 激活微信最近位置，显示图形降级，结束 Hold。 |
| Hold | 右键桌宠选择结束往返 | 留在当前位置，结束 Hold。 |
| Hold | 手动离开 Agent 到非锚点界面 | 开始默认五分钟的可调宽限期；回到 Agent 时暂停。 |
| Hold | 宽限期到期 | 静默结束 Hold，来源图标快速淡出，不响铃。 |
| Hold | 来源已关闭，或 char 重启 | Hold 失效。 |
| 普通 | 来源是 Warp pane，但只能捕获 Warp 应用 | 点击气泡仍激活目标工作端；不建立 Hold。 |
| Hold | 已准确捕获的 Warp pane 后来无法聚焦，但 Warp 可激活 | 返回 Warp 最近位置，显示降级结果，结束 Hold；此路径延期到准确捕获能力可用后。 |

返回只选择原来仍存在的界面，不重新打开已关闭的标签、聊天或编辑器。Tabbit 标签移动或在同一标签打开新网页时，锚点跟随该标签。Tabbit、VS Code 通过可用集成捕获并返回原来的具体界面；捕获不可靠时不建立 Hold。微信首版保存仍存活的应用实例作为降级来源，以图形标记应用级 Hold，点击桌宠激活微信最近位置并结束 Hold，不保证原聊天。Warp pane 的准确捕获和返回延期；仅识别到 Warp 应用时不能建立返回锚点。

当前 Warp Stable 无可用的准确 pane 控制路径。点击 CLI 气泡时首版只激活 Warp 最近位置；Codex Desktop 首版也只激活该工作端最近位置，准确聊天跳转延期。这些降级跳转不清除注意力项，来源被准确捕获时仍建立 Hold。降级结果仅用图形反馈，不在气泡或错误提示中使用可见文字。
目标 Agent 的原 Warp 标签已关闭但 tmux pane 仍在时，首版仍只激活 Warp 最近位置并保持注意力项未查看；新建 Warp 标签自动重接原 pane 延期。

## 动效提案

桌宠只在当前操作窗口转移到另一块屏幕时传送；鼠标仅经过另一块屏幕不触发移动。旧屏幕快速收束，新屏幕在记住的位置立即显现，动效总时长控制在约 180 毫秒内，气泡从第一帧起即可点击。频繁来回切屏时可直接切换，避免反复播放。系统启用减少动态效果时，改为无位移动画的短淡入淡出。桌宠采用与注意力和传送机制相配的原创形象，具体形象和时间以原型实测调整。

## 例子

- Tabbit 标签 A → Claude Code → Codex Desktop → 点击桌宠：回到原来的标签 A。
- 微信 → Codex CLI → 点击桌宠：激活仍存活的微信应用最近位置，显示降级标记，结束 Hold。
- 微信 → Codex CLI → 手动回微信任意聊天：应用级 Hold 静默结束，首版不区分原聊天。
- Tabbit 标签 A → Claude Code → 手动去微信两分钟 → 回 Claude Code：宽限期暂停；再手动去 VS Code 三分钟且不点击桌宠：累计达到五分钟，Hold 静默结束。
- VS Code 编辑器 A → Warp 中的 Agent → 手动返回编辑器 A：Hold 静默结束。
- 点击气泡只激活 Warp 最近位置、未进入目标 pane：Hold 保留来源，注意力项仍未查看。

## 首版验证门槛

- 对支持的各本机工作端分别验证提问、审批、轮次结束、异常与限制的检测；不能准确分类时显示未分类停顿。短于 10 秒的暂态停顿不提醒，达到阈值后出现的气泡即使 Agent 自行继续也保持未查看状态。
- 验证 Warp + tmux 中启动早于 char 的会话仍可被观察；CLI 气泡只激活 Warp 最近位置、保留注意力项并以图形反馈降级。Codex Desktop 首版只激活应用最近位置，显示图形降级且不清除注意力项。
- 分别验证通过可用集成捕获的 Tabbit 原标签、VS Code 原编辑器或终端标签的准确返回，以及微信应用级图形降级返回；这些来源关闭时 Hold 自动失效，不重建其内容。Warp 来源只识别到应用时验证不建立 Hold。
- 验证多个 Agent 连续访问后仍回最初来源、手动回来源静默结束 Hold、跨 Space 与全屏显示、多屏传送期间气泡持续可点。
- 图形图例需让使用者分辨原因类别、已恢复项和降级跳转；这些图形的可理解性须用原型验证，不能仅凭图标名称推断。
