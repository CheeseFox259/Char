# Char 1.2.0

让提醒更清晰、桌宠呈现更稳定，并扩展形象包可配置的标准接口。

## 更新

- 按原因播放需关注、发生问题和轮次结束提示音。互动音效随机选择形象音频，点击可立即打断上一条；点击气泡不再播放音效。
- 未查看的提醒气泡会在 5 分钟内从 44 pt 平滑增长到 66 pt，到达上限时再次提示一次。聚合项各自保留年龄，静音、折叠与隐藏不影响计时。
- 重构设置分类与折叠区域，将状态图形说明放回实际使用位置；整行标题均可点击展开和折叠。
- 修复 Claude `/exit` 后已结束的任务仍显示运行的问题，并调整异常输出识别。
- 改善桌宠拖动、跨屏迁移、Space 可见性恢复、真实尺寸下的绘制范围及菲比眼睛跟随；边缘露出至肩部，并添加低遮挡的柔光渐变边界。
- 为形象包扩展可选的原因音效、随机互动音频和边缘线配置；保留 schemaVersion 2 兼容性，并更新示例、开发指南和格式校验。

## 验收

自动检查覆盖提醒原因、聚合气泡计时、Claude 退出日志、设置状态、Space 通知重入及形象格式。原生检查覆盖多种尺寸、主题和放置；GUI 检查确认设置标题整行可展开。真实鼠标操作、用户的多屏快速 Space 切换、客户端会话与硬杀进程行为按[人工验收指南](experience-acceptance.md)进行；强制结束且无退出事件或 Hook 的会话无法仅凭现有日志可靠判定关闭。

## 安装

- `Char-1.2.0-macos-universal.dmg`：拖入应用程序安装。
- `Char-1.2.0-macos-universal.zip`：应用压缩包。
- `Char-1.2.0-examples.zip`：MiniMax CLI/Desktop 插件和新版菲比形象。
- `SHA256SUMS`：附件校验和。

更新前退出 Char，替换 `/Applications/Char.app`；已有配置与已安装形象保留。macOS 13+，Apple Silicon / Intel。发行包采用 ad hoc 签名，未经过 Apple 公证；首次启动可能需要在 Finder 中右键应用并选择“打开”。
