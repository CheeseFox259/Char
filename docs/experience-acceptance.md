# Char 体验优化：人工验收

本轮代码、资源和自动检查已完成。以下是真实操作的验收指南，重点是鼠标手感、Space通知和客户端实际信号。未做过的项目标“未测”，不要为了凑齐原因刻意触发费用或破坏会话。

## 打开独立验证版

1. 退出当前旧版Char，不删除原配置或已安装应用。
2. Finder“前往文件夹”输入 `<Char仓库路径>/build/experience-preview/`，打开其中的 `Char.app`。不拖到Applications，不开启登录启动。验证配置在同目录 `Profile/`，正式版配置独立。
3. 状态栏→设置→通用可选中文；桌宠与交互→导入形象，选择 `<Char仓库路径>/examples/appearance/feibi/packages/feibi.charpet`。可启用本例脚本。若验证Profile已有旧菲比，先删除该测试副本再导入，不动正式版。
4. “使用形象行为偏好”保持开启。先用48pt/日光，随后测试默认Char、月夜与36/88pt。

仓库移动后，上述路径使用对应新位置。验证App无需替换正式版。

## 建议先测这五项

| 操作 | 应看到的结果 |
| --- | --- |
| 在桌面中间拖动菲比，再立即释放；重复快拖 | 新位置保留，没有消失再出现。拖到可用桌面边缘才发生模式过渡；不跳回拖动前的位置。 |
| 分别选上、下、左、右边缘，停住鼠标，然后悬停、点击 | 露出到肩部；idle和互动曝光一致。探出位置有白色渐变细线，中央稍粗、两端细且渐隐，柔光不遮挡菜单栏或桌面，也不能拦截点击。 |
| 在48pt从八方向移动鼠标，经过一次眨眼 | 瞳孔约1pt可见位移，方向跟随屏幕坐标；旋转/镜像后也正确，无双影、瞳孔不跑出眼眶。 |
| 快速换Space，再返回；重复5次。另做普通窗口遮挡 | 系统显示后直接维持当前画面，不再播放宿主恢复/进场，不闪烁。另只切换一块屏幕的Space，桌宠不应往返跳屏；主动把焦点移到另一屏并停留后仍应跟随。 |
| Claude短请求完成后输入 `/exit`，或 `/quit` | 不再显示运行数量。未查看的完成项可以保留为淡化入口，查看成功或右键忽略后消失。再开一次新会话，运行信号仍能正常出现。 |

Claude补充检查：分别用Ctrl+D和关闭终端退出，记录是否出现相同残留。强制结束且既无退出日志也无SessionEnd Hook时，当前日志源无法可靠证明进程已关闭；不要把这个项目算通过。此轮已修复实际日志中的“/exit及退出输出被当成新提示”问题，没有按无活动超时猜测关闭。若终端所属应用已退出导致跳转失败，右键忽略应仍能清除淡化项。

## 声音与气泡

设置→注意力与声音，打开播放声音，三类分别试听：需关注=`phoebe_0`，问题=`phoeba_chubby_1`，轮次结束=`phoebe_chubby_4`。每类可以单独选择文件、恢复形象默认；旧自选声音会迁移为三类覆盖。

- 连续点击桌宠：从其余15条音频随机选择，下一次立即打断前一次；随机允许连续同一条。点击气泡不发默认声音。
- 有真实结构化提问/审批、失败/限流、轮次结束时，分别听对应类别。重复观察不重播，原因发生有效变化才产生新反馈；运行和等待确认不响。没有该原因信号的客户端标未测。
- 同时出现不同类别时，每类一次、按需关注→问题→轮次结束依次播放。提醒期间点击桌宠保留视觉反馈，不排队互动音。
- 静音后仍计龄。恢复声音不补播已消耗的提醒；排队项在实际播放前若已查看/恢复，不再播放。

保留一个未查看、仍等待的项，记录首次出现时间：

| 年龄 | 预期普通气泡直径 |
| --- | --- |
| 0秒 | 44pt |
| 60秒 | 约54.7pt |
| 299秒 | 接近66pt |
| 300秒 | 66pt；约0.25秒合并后再次提醒一次 |
| 301秒以后 | 保持66pt，不重复发声 |

新增项不重置旧项年龄；查看/忽略驱动项后改用剩余最早项；恢复/关闭停止增长和重播，淡化入口仍可点。没有等待项时恢复44pt。折叠小泡保持紧凑，展开显示真实年龄；隐藏或睡眠不暂停计龄，重启不回放历史提醒。到66pt后悬停、滚动、点击和破碎动画应匹配命中，不能点到邻泡。

## 设置与回城

点击标题、箭头或标题行空白均可展开/折叠；键盘Tab定位后空格也可操作。检查六类可折叠；关闭设置和重启后折叠状态保留。没有单独图例，图形样例在使用位置，问题/需关注/轮次结束可按形状区分。已恢复用回转箭头且淡化；回城旁分别说明准确、应用级和不可用。切英文后无未翻译的新增说明。故意选择不可播放文件或无效形象时，错误出现在所属分类。

Ctrl+B沿用原有回城规则；关闭目标时失败应可见，不声称准确回到会话。过滤在注意力分类，离开Agent后的宽限期在回城分类。

## 收集异常时间线

设置→性能与诊断→开启“记录桌宠通知时间线”。复现Space重复、拖动闪现或贴边问题后，点“显示记录”；文件为验证Profile中的 `presentation-trace.log`。测试结束关闭记录，重启也会关闭。记录仅含事件时间、窗口位置、可见性与动画状态，不含聊天正文。

反馈建议填写：形象/主题/大小/边缘；操作顺序；预期与实际；是否稳定复现；大致发生时间；对应日志末尾20行。截图尽量只包含桌宠区域。Claude问题注明退出方式、是否安装SessionEnd Hook、气泡显示的运行/未查看数量，无需提供会话正文。

性能面板开启后静置、打开设置、连续互动分别观察CPU、physical footprint和图片缓存。RSS单独看，不与footprint混用。单次数字有波动，本轮[验证记录](experience-verification.md)记录了同条件前后样本与局限。

## 恢复

退出验证版，再打开 `/Applications/Char.app`。原配置与形象保留。验证Profile为测试数据，后续更新验证版不必修改正式版配置。
