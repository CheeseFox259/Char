# 一次 Agent 往返只保留最初的返回锚点

char 在首次点击气泡时尽可能记录准确的返回锚点；2026-10-03 使用者批准微信首版改为明确标记降级的应用实例，返回只激活同一仍存活的应用最近位置，不保证原聊天，精准能力另行跟踪 #12。Tabbit、VS Code 捕获不可靠时不建立 Hold，Warp 应用级来源也不建立 Hold。连续访问其他 Agent 或手动切换页面都不覆盖它，点击桌宠直接聚焦原界面。使用者要回到开始处理 Agent 前的位置，逐次后退的导航栈会把人带回途中经过的 Agent；当来源关闭、char 重启或离开 Agent 后的宽限期到期时，Hold 结束。具体状态转移见[注意力往返行为](../attention-trip.md)。
