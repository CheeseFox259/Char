# 一次 Agent 往返只保留最初的返回锚点

char 在首次点击气泡时尽可能记录准确的返回锚点；2026-10-03 使用者批准微信首版改为明确标记降级的应用实例，返回只激活同一仍存活的应用最近位置，不保证原聊天，精准能力另行跟踪 #12。Tabbit、VS Code 的准确适配器捕获不可靠时不建立 Hold。2026-10-04 使用者批准可导入、启停和删除来源插件，修订此前“Warp 应用级来源不建立 Hold”的限制：使用者显式启用的应用级来源可建立同一存活应用实例的降级锚点，包括同时承载 Agent 的 Warp 等应用；它不宣称准确恢复窗口、标签或会话。默认来源仍为 Tabbit、VS Code 与微信，未经配置的应用不自动成为来源。停用或删除当前来源会结束 Hold。连续访问其他 Agent 或手动切换页面都不覆盖它，点击桌宠直接聚焦原界面。使用者要回到开始处理 Agent 前的位置，逐次后退的导航栈会把人带回途中经过的 Agent；当来源关闭、char 重启或离开 Agent 后的宽限期到期时，Hold 结束。具体状态转移见[注意力往返行为](../attention-trip.md)。

2026-10-04 后续修订：[ADR 0007](0007-unified-integrations-and-free-origins.md) 取代本文的来源允许列表、准确捕获失败不建立 Hold、停用来源一律结束 Hold 的限制；首次锚点与连续访问不覆盖的决定保持有效。
