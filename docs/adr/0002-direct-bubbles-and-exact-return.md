# 用桌宠旁的气泡直达原生会话

char 用常驻桌宠旁、按工作端聚合的图形气泡呈现注意力项；点击气泡直接尝试进入一个准确原生会话，同一工作端的其他项随后接续。使用者需要一次点击切回 Agent，因此菜单栏或先展开列表的路径不合适。当前 Warp Stable 没有可用且经验证的 pane 控制路径，首版 CLI 气泡只激活 Warp 最近位置，以图形标记降级，不将注意力项标记为已查看；准确 pane 聚焦和关闭标签后的重接延期。Codex Desktop 的准确聊天跳转仍是首版要求。Warp + tmux 未来的精准跳转可使用一次性终端集成与 macOS 辅助功能权限，但需先以实机证明。具体交互见[注意力往返行为](../attention-trip.md)。
