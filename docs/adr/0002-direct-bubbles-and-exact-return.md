# 用桌宠旁的气泡直达原生会话

char 用常驻桌宠旁、按工作端聚合的图形气泡呈现注意力项；点击气泡直接尝试进入一个准确原生会话，同一工作端的其他项随后接续。使用者需要一次点击切回 Agent，因此菜单栏或先展开列表的路径不合适。当前 Warp Stable 没有可用且经验证的 pane 控制路径，首版 CLI 气泡只激活 Warp 最近位置，以图形标记降级，不将注意力项标记为已查看；准确 pane 聚焦和关闭标签后的重接延期。2026-10-03 使用者批准所有工作端先采用应用级图形降级，因此 Codex Desktop 首版也只激活应用最近位置并保留未查看项；精准聊天另行跟踪 #11。Warp + tmux 未来的精准跳转可使用一次性终端集成与 macOS 辅助功能权限，但需先以实机证明。具体交互见[注意力往返行为](../attention-trip.md)。


## 2026-10-05：成功点击后清除本次提醒

使用者要求左键进入气泡后立即消失并播放破碎动画。成功的准确跳转和应用级降级都清除本次点击的一个注意力项；失败保留重试。导航精度保留在独立反馈中，应用级激活仍不宣称进入原 pane 或聊天。此前“降级不清除注意力项”的决定由此替换。

同一工作端的其他注意力项继续显示，运行中会话计数也继续显示；只有没有其他提醒和运行中会话时，整个聚合气泡才消失。第一次保存的 Hold 起点不受清除提醒影响。动画使用点击完成时的真实图层位置与图像，最多两组九片短暂碎片，以位移、缩小、旋转、淡出实现；减少动态效果时改为单片淡出，结束即移除图层。

## 2026-10-06：状态切换期间保持气泡连续

运行中会话进入停顿后，停顿过滤阈值仍决定何时创建注意力项和提醒音，但不再使既有运行气泡暂时消失。等待确认是该会话的临时展示状态；仅新观察到已停顿且没有运行信号的会话仍遵守原过滤规则。关闭、查看与忽略不因此复活提醒。状态标记与壳体分层，壳体、图标与位置持续保留，标记以非线性淡化和轻微弹性变化衔接；减少动态效果时仅短淡化。
