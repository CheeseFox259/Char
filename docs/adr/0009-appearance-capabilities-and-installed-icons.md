# 0009：外观能力包与安装图标

2026-10-07，依用户明确要求扩展原来的纯PNG形象合同。保留v1，新增v2声明式姿态、跟随层、主题、皮肤、音效和交互偏好；条件行为用进程外JavaScriptCore的Char事件/动作接口，用户选择不开放任意本机命令。高频跟随、动画和几何保持原生，避免脚本逐帧开销；监控、返回锚点和导航结果仍由现有宿主与集成插件负责。

用户选择“选中形象时自动同步Finder/Launchpad图标”。Finder资源叉方式破坏严格签名，因此改为保留原Release的安装备份、暂存资源修改、重新ad hoc签名和验证后事务替换；默认形象恢复原图标。此决定取代先前指南中“安装图标永远保持默认”的限制。Developer ID安装不自动改签；重签可能改变辅助功能信任，系统图标缓存呈现留用户验收。

用户可关闭形象行为偏好恢复自己的回城、焦点和布局设置。v2脚本没有OS桥、使用有界串行协议及超时终止；进程隔离不声称为系统权限沙箱。第三方作者依SDK完成资源/协议基本验收，再交付完整GUI验收步骤；真实使用由用户负责。
