# ADR 0010：注意力反馈与桌宠呈现的标准 seam

日期：2026-10-08。状态：采纳。延续 ADR 0008、0009。

提醒只传递“发声”会丢失原因、停顿身份与阶段，迫使形象包从聚合气泡倒推事件。窗口动画分散管理拖动、Space和反馈时钟，造成重复恢复、普通拖动闪现和命中与绘制不一致。菲比空白身体idle与有身体hover又放大了这一差异。

采用两个 deep module：AttentionFeedback接收注意力项和时间，拥有停顿身份、原因去重、合并、计龄与一次再次提醒；CompanionPresentation接收拖动提交、放置、可见性、Space与反馈，拥有动作取消、优先级与姿态时钟。其小 interface 是直接回归检查的 seam；原生声音、窗口/图层和形象资源作为 adapter。内置向量和菲比分层是两个真实 adapter，保持 locality，新增形象获得 leverage，无需复制计时。

声音播放由一个原生所有者串行提醒、抢占互动并在播放前重验有效性。静音消耗提醒机会且保留形象事件。画布预留66pt气泡、悬停与最大轨道；贴边可见范围固定在usable desktop，绘制位图先保留旋转/锚点后的像素，命中使用同一变换树。设置与桌面共用状态图形 module。

保持形象schemaVersion 2，增加可选soundBindings、随机files、零冷却、眼眶clipRegion、比例edgeInset和提醒阶段事件；旧字段继续有效，新字段要求本次配套宿主。年龄与再次提醒属于宿主，包仅负责表达。高频跟随/绘制仍原生，脚本仍进程外JavaScriptCore，不新增通用行为插件类型或可替换渲染技术。

Space公开通知可能在系统转场后到达；宿主只在确认隐藏恢复时执行0.16秒恢复，普通遮挡恢复不启动包进场。通知重复以实际时间线和受控输入检查；跨屏、不同系统通知顺序需要额外实机验证。

## 用户日志驱动的修正（2026-10-08）

首轮0.16秒恢复仍在快速Space切换中重复显示/闪烁。用户时间线记录了occlusion将opacity清零后再次恢复，以及同一切换附近两块屏幕来回迁移且moving=true。可见性通知是WindowServer结果，不能再作为宿主离场/进场触发。移除恢复时钟、缩放和缩回，仅由系统呈现跨Space；通知用于暂缓焦点屏幕选择。普通屏幕跟随必须在可见且Space稳定后，连续0.45秒观察到同一候选；Space通知后至少暂缓0.55秒，可见性变化后至少0.4秒。未知/改变候选清除计时。此时长为首个回归策略，真实多屏快速切换仍需用户复验。

边缘光作为可选edgeBoundary表达字段，由原生adapter绘制，不属于形象动作或点击区域；固定桌面遮挡层与可外扩的柔光分开。菲比edgeInset从0.20改为0.09，保持anchor0.64，遮挡线从画布0.84收至0.73附近，露出到肩部。
