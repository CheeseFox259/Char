# 统一集成能力并自由记录往返起点

2026-10-04 使用者要求 Agent 之间也能跳转再回城，因此集成配置统一为可同时提供提醒和准确回城的能力，而任何前台应用（Char 自身除外）都可成为应用级往返起点。该决定取代 [ADR 0005](0005-single-return-anchor.md) 的来源允许列表及准确捕获失败不建立 Hold 的限制：准确适配器不可用时明确保存应用级锚点；停用提醒不使应用级锚点失效，移除准确适配器则使依赖它的准确锚点失效。

首次锚点仍贯穿连续的 Agent 访问，应用级激活仍显示降级且不标记注意力项已查看；自由记录不增加读取聊天正文的权限，也不宣称恢复准确窗口或会话。旧插件 ID、启停状态、删除记录和版本 1 配置保留，迁移为能力格式，避免升级重置用户选择。
