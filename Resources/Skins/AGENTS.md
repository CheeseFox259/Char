# Char 外观形象包开发

在本目录开始任务时，按当前用户的视觉需求制作完整、可导入的 `.charpet`。角色、风格、尺寸和动作设计来自任务，不预设某一种造型。

以下仓库路径相对仓库根目录；构建与校验命令从仓库根目录运行。

## 制作流程

1. 阅读 `docs/appearance-development.md`、`docs/pet-skin-format.md` 和 `Sources/CharPlatform/PetSkins.swift` 的生产校验。明确角色身份、动作语言与输出目录；缺少关键视觉目标时集中提问。
2. 规划七组动作 `idle`、`press`、`return`、`depart`、`arrive`、`edgePeek`、`edgeHide`，在格式预算内选择画布、帧率和帧数。保持 anchor、比例和视觉身份一致；首尾衔接与非线性压缩/回弹通过完整动作预览判断。
3. 生成真实透明 8-bit RGBA PNG，manifest 实际枚举有序帧。包内仅保留清单和被引用资源，生成器、预览与说明置于包外。包是数据，不执行代码；当前格式没有自定义鼠标视线通道。
4. 将动作与 Char 的整体缩放、平移、边缘旋转和 Reduce Motion 叠加检查，避免双重收缩、越界裁切和忽然复原。外观包只改变角色图像。
5. 运行 `swift run char-package-check skin <包绝对路径>`，修复至退出码 0。检查透明像素、尺寸、非空画面，并实际查看七组动画和 idle 循环；文件数量不代替视觉验收。
6. 经用户授权选择测试形象后，检查桌面/四边、尺寸范围、交互、跨屏、Reduce Motion、重启和删除回退。记录唯一帧数×宽×高×4的解码像素估算及实际性能测量条件。

## 完成标准

交付实际包、生成器、完整动作预览、校验结果、安装/更新/删除说明及性能边界。设置导入会立即选择形象；同 ID 更新需按当前产品流程处理。未运行的互动与性能项明确标注，修复视觉问题后复查最终包。
