# Char 外观形象包开发指令

在此目录开始任务时，按当前用户的视觉需求制作完整可导入 `.charpet`。角色、风格、尺寸、动作和软件图标设计来自任务，不预设任何造型。缺少关键视觉目标时集中提问，同时检查格式和现有预览工具。

路径相对仓库根，命令从根执行。先读 `docs/appearance-development.md`、`docs/pet-skin-format.md` 和 `Sources/CharPlatform/PetSkins.swift` 的生产校验；读 `docs/architecture.md` 理解宿主变换。外观包保持纯图像数据，不使用能力插件进程协议，也不插入监控/导航脚本。

## 制作

1. 明确角色身份、动作语言、输出目录与预算。规划 idle、press、return、depart、arrive、edgePeek、edgeHide 七组动作，在生产帧率/帧数/像素/字节限制内安排画布、anchor、顺序帧和循环。
2. 保持比例、身份、anchor 和透明边界一致。通过非线性压缩/伸展、缓入缓出与受控回弹表达弹性，确保 idle 首尾衔接；用完整动作预览判断，不以文件数量替代自然度。
3. 为同一角色制作独立 appIcon，正方形128/256/512/1024像素8-bit RGBA透明PNG，推荐1024。图标计入包预算，检查18px状态栏、64px软件图标辨识度。运行图标随形象切换；安装包默认图标不改，以保持签名。
4. 生成真实透明8-bit RGBA PNG；manifest 实际列出有序资源。包只保留清单和引用资源，生成器、预览和说明放包外；不含符号链接或代码。当前格式不支持自定义程序化眼睛跟随通道，不承诺位图有该能力。
5. 将帧动画与宿主整体缩放、平移、边缘旋转、气泡联动、Space显隐、跨屏和Reduce Motion组合检查，避免双重收缩、裁切、突然复原与过长转场。形象不重写宿主交互规则。
6. 用 swift run char-package-check skin <包目录> 校验，修复至退出码0。检查透明像素、尺寸、非空画面；实际观看七组完整动画与idle循环并保存可看的预览。
7. 有授权后导入最终包，验证桌面/四边、大小范围、点击与回城、跨屏、Reduce Motion、重启、软件/状态栏图标同步和删除回退。外观不会赋予客户端监控或准确回城能力。
8. 记录唯一解码帧数×宽×高×4的内存估算及实测CPU/RSS，注明尺寸、气泡数、设置预览、样本时长和环境。避免重复帧和无意义高帧率，不牺牲动作可见性换性能数字。

## 完成标准

交付真实包、可重现生成器、完整动作/图标预览、生产校验、交互与性能结果、安装/同ID更新/删除/回退说明。更新行为以当前PetSkinStore和产品流程为准，不能借用集成包更新规则。未运行项明确列出；最终视觉改动后复查交付包。指令不自动授权用户配置写入或发布。
