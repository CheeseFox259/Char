# Char 配置插件开发

在本目录开始任务时，按用户需求开发可直接导入的 `.charintegration` 配置包。此指令是通用流程，插件名称、目标应用和能力由当前需求决定。

以下仓库路径相对仓库根目录；构建与校验命令从仓库根目录运行。

## 开发流程

1. 阅读根目录 `CONTEXT.md`、`docs/plugin-development.md` 和 `docs/integration-plugin-format.md`。检查 `Sources/CharCore/IntegrationPlugins.swift` 的生产校验与已编译能力。
2. 确认目标工作端、提醒能力、回城精度和目标应用 bundle ID。缺少必要信息时用一个问题补齐，同时进行不依赖答案的查证。客户端事实来自官方资料或已安装客户端，附证据。
3. 选择已有 `workEnd` 和 `returnAdapter`；配置包只声明能力和资源，不运行代码。需要新协议或新适配器时转到 `integrations/AGENTS.md` 的源码流程，明确交付范围。
4. 按生产格式生成完整包，选择唯一 ID，校验资源路径、图标与启用冲突。包外保存开发说明、安装、更新和删除/恢复步骤。
5. 用 `swift run char-package-check integration <包绝对路径>` 校验实际交付包，退出码必须为 0。无效包修复后重新校验；格式通过与实际客户端跳转分别记录。
6. 若用户授权导入，验证启停、删除、冲突提示和对应导航；保留既有配置。原生 Hook 安装、系统权限和发布按用户授权范围执行。

## 完成标准

交付真实包、能力及限制说明、证据、安装与恢复步骤、实际校验结果和未运行的验收项。精确聚焦有证据才能标为准确回城；应用激活属于应用级回城。修改格式时同步生产校验、检查和格式文档。
